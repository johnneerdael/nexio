# Android Getting Started

## Purpose
Provide a reliable first-run workflow for configuring and validating Nexio Android playback.

## Audience
- New Android users
- Testers setting up a clean validation environment

## Prerequisites
- Installed Android app
- Network access
- At least one configured addon in the web workspace

## Procedure and Guidance
1. Launch the app and confirm the initial screen loads without errors.
2. Sign in with the intended account and verify account identity.
3. Open Home and confirm at least one catalog row is available.
4. Open a title in Media Detail and inspect metadata context.
5. Start playback from a stream and verify controls, back behavior, and exit path.
6. Open Settings to confirm account and integration surfaces are reachable.

## Validation and Expected Outcome
- Home, Detail, and Player navigation path works end-to-end
- Account context is stable
- Playback starts and exits predictably

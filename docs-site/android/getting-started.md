## Android App Getting Started Guide

## 15-minute onboarding flow

### Step 1: Open the app
**Action**: Tap the app icon on your home screen
**Expected result**: App opens to the main screen
**Time**: 1 minute

**Failure recovery**: If app doesn't open:
- Check if app is installed
- Restart your phone
- Clear app cache in settings

### Step 2: Sign in
**Action**: Enter your username and password
**Expected result**: You see your dashboard
**Time**: 2 minutes

**Failure recovery**: If login fails:
- Check your internet connection
- Verify username and password
- Reset password if needed

### Step 3: Add addon
**Action**: Tap "Add Addon" button
**Expected result**: Addon selection screen appears
**Time**: 3 minutes

**Failure recovery**: If addon doesn't load:
- Check internet connection
- Try different addon
- Contact support if issue persists

### Step 4: Pick content
**Action**: Browse and select content you want to watch
**Expected result**: Content details screen shows
**Time**: 4 minutes

**Failure recovery**: If content doesn't load:
- Try different content
- Check internet connection
- Clear app data and restart

### Step 5: Open stream list
**Action**: Tap "Stream" button on content details
**Expected result**: Available streams list appears
**Time**: 3 minutes

**Failure recovery**: If streams don't appear:
- Wait 30 seconds for loading
- Try different content
- Check server status

### Step 6: Start playback
**Action**: Tap on a stream to start playing
**Expected result**: Video starts playing
**Time**: 2 minutes

**Failure recovery**: If playback fails:
- Try different stream quality
- Check internet speed
- Restart app and try again

## Congratulations!
You've completed the basic onboarding in 15 minutes.

## Troubleshooting
**Common issues**:
- App crashes: Restart your phone
- Slow loading: Check internet connection
- No streams: Try different content
- Login issues: Reset password

**Quick fixes**:
- Force stop app and restart
- Clear app cache
- Update app to latest version
- Contact support for persistent issues

# Android Getting Started

Use this page as a quick first-run checklist for the TV app. The full account prep and cache expectations live in Start Here, but testers still need a short smoke test here.

## Before you begin
- Finish the website setup first.
- Sign in on the TV app with the same account.
- Give sync a moment to bring in Trakt and catalog data.

## First-run checklist
1. Launch Nexio and let Home load.
2. Verify Home shows usable content instead of staying empty.
3. Open a title and check the detail page.
4. Start playback and confirm the player opens and returns cleanly.
5. Open Settings and confirm the categories you expect are present.
6. If Home still looks sparse, wait for the disk-backed cache to warm up before calling it broken.

## If something looks wrong
- No catalog rows usually means the website setup is incomplete.
- A slow Home load can still be normal on first launch.
- If playback fails repeatedly, check the stream selection and playback settings.

# Android Getting Started

## First run
Use this path when you are opening Nexio for the first time or validating a clean install on a TV device.

## Before you begin
- Install Nexio on the TV device.
- Make sure the device is online.
- Confirm your account, addons, and catalogs are already configured in the web portal or account flow.

## Recommended walkthrough
1. Launch Nexio and let the initial Home screen load.
2. Confirm your account is the expected one if the app shows account context or sync data.
3. Check that Home shows at least one useful section, such as Hero, Continue Watching, or a catalog row.
4. Open a title and review the detail page before starting playback.
5. Start a stream and confirm the player opens, responds to Back, and returns to the previous screen cleanly.
6. Visit Settings and confirm the categories you expect to use are present.

## What to expect
- Home should not stay stuck on loading forever.
- Detail should show meaningful metadata, actions, and a clear play path.
- Playback should start, pause, and exit predictably.
- Settings should expose the integrations and playback controls you need without leaving the TV app.

## If something looks wrong
- No catalog rows usually means no catalog-enabled addons are available.
- A slow Home load can still be normal on first launch, but it should recover or show a retryable state.
- If playback exits unexpectedly, check stream selection and playback settings before assuming the source is broken.

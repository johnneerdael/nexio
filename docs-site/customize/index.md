# Customize

Customize is where you shape what the TV app shows and how it reads. The easiest place to manage these controls is the website, but the result is always an app experience: cleaner rows, clearer stream cards, and less guesswork when people browse.

## Start with these guides

- [Catalog Views and Personalization](/customize/catalog-views-and-personalization) - order catalogs, shape Home, and keep browsing focused.
- [Universal Formatter](/customize/universal-formatter) - use the new formatter template to make stream cards easier to scan.

## When to use this section

Use Customize after the account is signed in and the basic integrations are working. This is the place to refine what people see first, not to set up the account from scratch.

## If something still looks wrong

Move to [Troubleshooting](/troubleshooting/) once the guides and portal settings are in place.

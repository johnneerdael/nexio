# Watching

Watching is the feature-first guide set for the TV app. Use it when you want to understand how Home, Detail, trailers, and playback fit together without reading screen-by-screen reference pages.

## Guides

- [Home and Continue Watching](/watch/home-and-continue-watching) - how the main feed is built and why it may change over time.
- [Details, Seasons, and Watching Flow](/watch/details-seasons-and-watching-flow) - play, resume, seasons, metadata, ratings, and recap-aware playback flow.
- [Trailers and Recaps](/watch/trailers-and-recaps) - trailer playback and recap skips.

## Good starting point

If Home feels empty or stale, return to [Start Here](/start-here/) before you keep digging. If playback or metadata is the real problem, jump to [Playback](/playback/) or [Integrations](/integrations/) instead of staying in Watching.

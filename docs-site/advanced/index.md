# Advanced

Advanced is the optional home for setup detail you only need when the default guides are not enough. Start with the main Customize, Integrations, Playback, and Watching pages first. Come here when you need fallback behavior, self-hosting detail, or deeper technical context.

## Primary advanced guide

- [Options and Self-Hosting](/advanced/options-and-self-hosting) - long-form companion for Streailer fallback and the self-hosted IMDb ratings API.

## Recovery and deeper references

- [Troubleshooting](/troubleshooting/) - the fastest place to back up and recover.
- [Developer Architecture](/dev/architecture) - the deeper implementation view when you need it.

## Technical references

- [Media3](/android/technical/media3) - the playback control plane and fallback behavior.
- [FFmpeg](/android/technical/ffmpeg) - the decoder fallback path for tougher formats.
- [libdovi](/android/technical/libdovi) - the Dolby Vision bridge used by advanced playback paths.
- [IEC Passthrough](/android/technical/iec) - the Kodi-derived audio sink and passthrough path.

## When to use it

Use Advanced when the standard setup already works and you are tuning fallback behavior, compatibility edge cases, or your own infrastructure. If you are still on the normal playback path, go back to [Playback](/playback/) instead of treating Advanced as the default journey.

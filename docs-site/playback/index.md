# Playback

Playback guidance now lives in a small set of practical, recommendation-driven guides. Start here if the default player works but you want better buffering, subtitles, or device compatibility.

## Recommended path

- If progressive streams buffer, seek poorly, or feel fragile, start with [Playback Tuning](/playback/playback-tuning).
- If you need translated subtitles, read [Subtitles and Auto-Translate](/playback/subtitles-and-auto-translate).
- If your device is weak, old, or sensitive to codec choice, use [Audio Codecs and Device Advice](/playback/audio-codecs-and-device-advice).
- If you are no longer sure whether this is a playback problem or a setup problem, back up to [Troubleshooting](/troubleshooting/).

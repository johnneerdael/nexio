# Integrations

Integrations keep the TV app and the website aligned around the same account. Start with the app-first guides below if you want to understand how each feature actually behaves in Nexio.

## Primary guides

- [Debrid and Service Wrap](/integrations/debrid-and-service-wrap) - set up provider-backed playback once and keep provider secrets out of each addon.
- [Library Integration](/integrations/library-integration) - turn debrid accounts into browsable library content.
- [Ratings and Metadata](/integrations/ratings-and-metadata) - set up TMDB, MDBList, OMDb, and the optional self-hosted IMDb path for richer detail pages and ratings.
- [Screensaver and Idle Experience](/integrations/screensaver-and-idle-experience) - understand the modern idle screen and why Trakt helps it feel current.

## Portal reference

- [Portal Integrations](/web/admin-workspaces/integrations) - account-wide setup, secrets, validation, and sync details for the web portal.

## What this section is for

This section is for the account-backed features that the TV app reads at runtime: debrid playback, library surfaces, ratings, metadata, and the idle screensaver.

# Security and Data

This bridge page points to the new Start Here security and account guidance.

## Portal-specific handling
Keep service credentials in the account flow, not in notes or screenshots. Nexio separates visible portal settings from sensitive service secrets, so the website is where you manage both intentionally.

## Where this matters
- Use the portal for account-linked setup and secret management.
- Sign out on shared browsers when you are done.
- Use the TV app only for the QR sign-in and active-device account check.

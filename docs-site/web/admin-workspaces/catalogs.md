# Catalog Inventory

Catalog Inventory is the portal-side view of Home ordering. For the user-facing effect of catalog shaping, start with [Catalog Views and Personalization](/customize/catalog-views-and-personalization) first.

![Catalog inventory](/images/management-portal/catalog-inventory.webp)
*Catalog Inventory is the place to reorder rails, trim overlap, and decide which discovery rows are visible on Home.*

## What it still controls

- reorder rows on Home
- disable a row without deleting the source behind it
- keep account-scoped catalog order in sync
- manage provider, Trakt, and MDBList rows from one place

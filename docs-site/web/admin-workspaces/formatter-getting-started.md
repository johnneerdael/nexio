## Who this is for
Beginner formatters who want to understand basic formatting concepts through simple examples.

## What you will build
A simple formatted text output that demonstrates core formatting principles.

## Before you start
1. Install the formatter tool
2. Open your text editor
3. Create a new file called `example.txt`

## First formatter example
```
# Simple formatter example

# Hello, World!

# Formatting options:
# - Bold: **Hello**
# - Italic: *World*
# - Underline: <u>Example</u>
```

## Tiny progressive edits
### Edit 1: Add color
```
# Add color formatting

# Hello, World!

# Formatting options:
# - Bold: **Hello**
# - Italic: *World*
# - Underline: <u>Example</u>
# - Red text: <span style="color:red">Red</span>
```

### Edit 2: Add alignment
```
# Add text alignment

# Hello, World!

# Formatting options:
# - Bold: **Hello**
# - Italic: *World*
# - Underline: <u>Example</u>
# - Red text: <span style="color:red">Red</span>
# - Center alignment: <div style="text-align:center">Centered</div>
```

### Edit 3: Add spacing
```
# Add spacing between elements

# Hello, World!

# Formatting options:
# - Bold: **Hello**
# - Italic: *World*
# - Underline: <u>Example</u>
# - Red text: <span style="color:red">Red</span>
# - Center alignment: <div style="text-align:center">Centered</div>
# - Spacing: <div style="margin:20px"></div>
```

## Check your result
- Verify text appears in different colors
- Confirm alignment changes
- Ensure spacing is visible

## Common mistakes
- Forgetting to close HTML tags
- Using incorrect syntax for formatting
- Overcomplicating simple formatting

## Next step
Learn about advanced formatting options in the [formatter reference](formatter.md)

## Troubleshooting
- If formatting doesn't work: Check for missing closing tags
- If colors don't appear: Verify browser support
- If alignment is off: Check CSS syntax

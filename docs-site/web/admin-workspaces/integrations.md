# Integrations

Most users should start with the app-first guides in [Integrations](/integrations/). This page keeps only the portal-specific reference that is still useful when you need to manage account-wide settings, secrets, or validation from the website.

![Integrations overview](/images/management-portal/integrations-overview.webp)
*The portal workspace shows connection health, current status, and the services that are already active for the account.*

## App-side handoff

- Trakt: [Home and Continue Watching](/watch/home-and-continue-watching)
- MDBList: [Details, Seasons, and Watching Flow](/watch/details-seasons-and-watching-flow)
- Subtitle Translation: [Subtitles and Auto-Translate](/playback/subtitles-and-auto-translate)
- Anime Skip and Poster Ratings: configured here in the portal and consumed by the TV app where those features appear.

## What the portal still does well

- Stores account-wide settings and secrets once, then syncs them back to the TV app.
- Validates provider credentials before the account snapshot is saved.
- Keeps list ordering and sync state in one place when the account is shared across devices.

## Portal reference

- Use the portal when you need to save account-wide values once instead of re-entering them on the TV.
- For ratings, OMDb is the normal path; the custom IMDb service is the advanced self-hosted path.
- For the rest, the portal keeps the account snapshot and sync state consistent across devices.

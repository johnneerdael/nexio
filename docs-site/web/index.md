# Web App Overview

Nexio Web is the management portal for your streaming ecosystem. It allows you to configure your account, manage additions, and fine-tune your streaming experience from any browser.

## Key Features
- **Account Sync**: Your settings follow you to every device.
- **Addon Management**: Install and configure Stremio-compatible addons.
- **Integrations**: Connect Trakt, Real-Debrid, and more.
- **Custom Formatter**: Personalize your stream metadata.

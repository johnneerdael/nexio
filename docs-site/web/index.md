# Web Overview

## Purpose
Introduce the web documentation path for account management, workspace administration, and operational configuration.

## Audience
- Web administrators
- Contributors supporting configuration and integration workflows

## Prerequisites
- Access to the Nexio web workspace
- Valid account credentials

## Procedure and Guidance
1. Begin with [Web Get Started](./get-started.md).
2. Use [Addon Manager](./admin-workspaces/addons.md), [Catalog Inventory](./admin-workspaces/catalogs.md), and [Integrations](./admin-workspaces/integrations.md) for staged setup.
3. Apply stream presentation changes with [Formatter Getting Started](./admin-workspaces/formatter-getting-started.md) and the [Formatter Reference](./admin-workspaces/formatter.md).
4. Keep account and security checks in scope with [Account](./account.md) and [Security and Data](./security-and-data.md).

## Validation and Expected Outcome
- Administrative setup is reproducible and traceable
- Configuration changes map to expected Android runtime behavior

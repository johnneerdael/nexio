# Account

## Purpose
Define how account-related actions are handled in Nexio web workflows, including sign-in state, connected sessions, and basic account maintenance decisions.

## Audience
- Web administrators managing their own account setup
- Team members validating account access behavior

## Prerequisites
- Access to the Nexio web workspace
- A valid account for the selected environment

## Procedure and Guidance
1. Sign in and confirm the expected account identity is shown.
2. Review account-level settings before changing integrations or formatter rules.
3. If multiple devices are used, verify that session state is consistent across them.
4. After account changes, re-check key workflows in web admin pages and Android playback flow.

## Validation and Expected Outcome
- Active account identity is correct
- Session behavior is stable across normal usage
- Downstream pages (integrations, catalogs, formatter) remain accessible

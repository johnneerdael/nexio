# Security and Data

## What this helps with
This page covers safe handling of account access, secrets, and synced account data in Nexio.

## Where you do this
Use the website for account-linked configuration and secret management. Use the TV app for sign-in, account confirmation, and sign-out on shared devices.

## Recommended setup
1. Keep addons, integrations, and catalog settings in the website.
2. Sign in on the TV app with QR instead of sharing credentials in chat or notes.
3. Treat service credentials as sensitive and keep them out of screenshots, tickets, and shared docs.
4. Sign out of shared browsers or TVs when you are finished.

## Advanced notes
- Synced account state is not the same thing as local browser state.
- Visible settings and sensitive credentials are handled separately, so you should manage both from the account UI instead of copying secrets around.

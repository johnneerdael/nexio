# Recommended Setup

## What this helps with
This is the shortest reliable first-time path for Nexio. It keeps setup app-first without making the TV app do work that is easier and faster on the website.

## Before you sign in on the TV
- Open the website first and prepare the account there.
- Set up addons, integrations, and catalog views on the website first.
- Keep your QR sign-in flow ready for the TV app.
- If you are switching accounts, sign out of the old one before starting the new setup.

## Recommended order
1. Set up addons, integrations, and catalog views on the website first.
2. Sign in on the TV app with QR.
3. Wait for Trakt and catalog sync.
4. Allow the disk-backed cache to warm up before judging whether setup is complete.

## What to expect on first login
- Home can appear in phases instead of all at once.
- Trakt-backed rows and catalog-backed rows may show up after the first screen is visible.
- Artwork, metadata, and row ordering can continue to settle after you sign in.
- A setup that is still filling in is not the same as a broken setup.

## If setup looks incomplete
- Recheck the website settings for addons, integrations, and catalog visibility.
- Confirm the TV app is signed into the same account you prepared on the website.
- Give Trakt and catalog sync enough time to finish before retrying.
- If Home stays empty after a reasonable wait, treat it as a likely misconfiguration.

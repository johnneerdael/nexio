<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External IDs to TVDB identity service | Untrusted remote IDs and source names enter normalization and lookup. |
| TVDB API result to Nexio identity model | Search results may contain non-series entities or spoofed remote IDs. |
| Concurrent browse paths to TVDB | Multiple callers can request the same identity simultaneously. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03-01 | Tampering | TvdbIdentityService | mitigate | Filter remote-id results to `series != null` before accepting identity. |
| T-06-03-02 | Spoofing | TvdbRemoteIdNormalizer | mitigate | Normalize known source names and preserve unknown IDs as `OTHER` instead of treating them as trusted sources. |
| T-06-03-03 | Denial of Service | TvdbIdentityService | mitigate | Use in-flight `CompletableDeferred` map and persisted cache before network calls. |
| T-06-03-04 | Information Disclosure | TvdbProviderFallback | mitigate | Log reason codes only; no credentials, bearer tokens, or raw URLs with query strings. |
</threat_model>

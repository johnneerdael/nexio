<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local settings to public sync payload | Non-secret TVDB settings become account settings JSON. |
| Local credentials to Supabase secret RPC | API key and optional PIN move into `account_secrets` through existing RPCs. |
| Supabase SQL allowlists | Server-side checks decide whether `tvdb_api_key` is accepted or rejected. |

| T-06-04-02 | Elevation of Privilege | AccountSettingsSyncService | mitigate | Use fixed `TVDB_SECRET_REF = "integration:tvdb"` and existing authenticated sync RPCs keyed by sync owner. |
| T-06-04-03 | Tampering | supabase/account_settings_sync.sql | mitigate | Add `tvdb_api_key` to every checked allowlist so all set/delete/resolve paths behave consistently. |
| T-06-04-04 | Information Disclosure | docs/settings/settings-sync.schema.json | mitigate | Static grep rejects secret field names in public schema. |
</threat_model>

<objective>
Preserve TVDB season ordering without destabilizing Trakt progress matching.

Purpose: TVDB's default season type is valuable metadata, but Nexio's current progress, ratings, and mutation paths depend on canonical season/episode pairs. This plan stores TVDB order context alongside canonical fields and keeps existing UI/progress behavior stable.
Output: Domain order context, TVDB season-order mapper, service integration, diagnostics, and tests.
</objective>

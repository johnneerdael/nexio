## Spacing Scale

Declared values in dp (Android TV 8-point grid):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon gaps, badge inner padding, lock icon offset |
| sm | 8dp | Compact element spacing, PIN dot gap |
| md | 16dp | Default element spacing, sidebar section padding |
| lg | 24dp | Sidebar vertical padding (existing), profile card gap |
| xl | 32dp | Settings screen horizontal padding (existing) |
| 2xl | 48dp | Selection screen vertical breathing room |
| 3xl | 64dp | Page-level centering offset on selection screen |

Exceptions:
- Sidebar width: 260dp fixed (existing `SidebarNavigation.kt` — do not change)
- Nav item height: 56dp (existing `SettingsRailItemHeight = 56.dp` — reuse for profile switcher rows)
- Settings container radius: 28dp (existing `SettingsContainerRadius = 28.dp`)
- Settings pill radius: 999dp (existing `SettingsPillRadius = 999.dp`)
- Touch target minimum: 44dp (all D-pad focusable cells must be at least 44dp tall)
- PIN numpad cell: 72dp × 64dp (wide enough for single digit at titleLarge, tall enough for 10-foot legibility)

Source: `SidebarNavigation.kt`, `SettingsDesignSystem.kt`

## Typography

All text uses the active user font (default: Inter variable). New composables must use `MaterialTheme.typography.*` — do not hardcode font size or family.

| Role | Style Token | Size | Weight | Line Height | Usage |
|------|-------------|------|--------|-------------|-------|
| Screen heading | `headlineLarge` | 28sp | SemiBold (600) | 36sp | "Who's watching?" on selection screen |
| Profile name (selection) | `titleLarge` | 20sp | Medium (500) | 28sp | Profile name below avatar on selection screen |
| Profile name (sidebar) | `titleMedium` | 16sp | Medium (500) | 24sp | Active profile name in sidebar header |
| Body / label | `bodyMedium` | 14sp | Normal (400) | 20sp | PIN entry prompt, rate-limit countdown, settings header subtitle |
| Badge / status | `labelMedium` | 12sp | Medium (500) | 16sp | "Default" badge on settings header, "Wrong PIN" error text |

Weights used: Normal (400) and Medium/SemiBold (500/600) — matches existing two-weight convention.

Focus state: text color transitions from `NexioColors.TextSecondary` (#B3B3B3) to `NexioColors.TextPrimary` (#FFFFFF) via `animateColorAsState`.

Source: `Type.kt` — full typography scale defined there. `SettingsDesignSystem.kt` — usage patterns.

## Color

All colors are drawn from `NexioColors` / `NexioTheme.colors`. Do not hardcode hex values in new composables — reference the token.

| Role | Token | Default Hex | Usage |
|------|-------|-------------|-------|
| Dominant (60%) | `NexioColors.Background` | #0D0D0D (theme-tinted) | Selection screen background, PIN overlay backdrop |
| Secondary (30%) | `NexioColors.BackgroundElevated` | #1A1A1A | Sidebar panel background, settings workspace surface, profile card surface |
| Card / elevated secondary | `NexioColors.BackgroundCard` | #242424 | Profile avatar card background (unfocused), PIN numpad cell background |
| Accent (10%) | `NexioColors.Secondary` + `NexioColors.FocusRing` | Theme-dependent | See reserved list below |
| Destructive | `NexioColors.Error` | #CF6679 | "Wrong PIN" text, PIN dot error state border/background |

Accent (`NexioColors.Secondary` / `FocusRing`) is reserved for:
1. Focus ring border on focused profile avatar card (2dp border, `FocusRing` color)
2. Focus ring border on focused PIN numpad cell (2dp border, `FocusRing` color)
3. Focus ring border on focused sidebar profile row (existing `SidebarNavItem` pattern — `FocusRing`)
4. "Default" badge background tint on settings header (FocusRing at 20% alpha)
5. Toggle pill fill when checked (existing `SettingsTogglePill` pattern)

Avatar circle background: use `profile.avatarColorHex` parsed via `android.graphics.Color.parseColor()` wrapped in `runCatching` — do not use a NexioColors token. Falls back to `#1E88E5` (Ocean) on parse failure.

Source: `Color.kt`, `ThemeColors.kt`, `SidebarNavigation.kt`, `SettingsDesignSystem.kt`

## Dimension Specifications

### Profile Avatar Sizes

| Context | Size | Shape |
|---------|------|-------|
| Selection screen avatar | 96dp | CircleShape |
| Selection screen avatar (focused) | scale 1.15x via `graphicsLayer { scaleX; scaleY }` | — |
| Sidebar active profile avatar | 40dp | CircleShape |
| Sidebar expanded profile list avatar | 32dp | CircleShape |
| Settings header avatar | 40dp | CircleShape |
| Lock badge on avatar | 16dp icon in 20dp circle | CircleShape, bottom-right offset |

Source: D-03 (scale-up ~1.15x at 10-foot), D-10 (lock badge), D-11 (sidebar), D-15 (settings header); sizes are Claude's discretion from CONTEXT.md.

### Focus Animation

| Property | Value | Source |
|----------|-------|--------|
| Focus animation duration | 210ms | NuvioTV verified: `tween(durationMillis = 210)` |
| Focus easing | CubicBezierEasing(0.22f, 1f, 0.36f, 1f) | NuvioTV verified |
| Avatar scale at focus | 1.15x (1f + 0.15f × focusProgress) | D-03: "~1.15x" |
| Focus border width | 2dp | Existing `SidebarNavItem` pattern |
| Focus border color | `NexioColors.FocusRing` (theme-dependent) | D-03: colored border glow; using accent color per Claude's discretion |

Note: D-03 leaves border glow color to Claude's discretion. Using `NexioColors.FocusRing` (theme accent) is consistent with existing focus patterns across the app rather than avatar color, which would vary per card and create visual inconsistency.

### Sidebar Expand/Collapse Animation

| Property | Value |
|----------|-------|
| Expand animation | `AnimatedVisibility` with `expandVertically(animationSpec = tween(200))` |
| Collapse animation | `shrinkVertically(animationSpec = tween(180))` |
| Expand arrow rotation | 0deg collapsed → 180deg expanded via `animateFloatAsState(tween(200))` |

Source: D-12; Claude's discretion for specific durations. Matches existing sidebar slide duration (~200ms).

### PIN Entry

| Property | Value |
|----------|-------|
| PIN overlay background | Full-screen `Box` over content with `NexioColors.Background.copy(alpha = 0.95f)` |
| PIN dot size | 16dp filled circle, 16dp outlined circle (unfilled) |
| PIN dot spacing | 12dp between dots |
| PIN numpad cell size | 72dp width × 64dp height |
| PIN numpad cell radius | RoundedCornerShape(12dp) |
| PIN numpad grid gap | 8dp horizontal, 8dp vertical |
| PIN shake offsets | -22f, 18f, -14f, 10f, -6f, 0f each at tween(42ms) |
| Rate-limit text | `NexioColors.TextSecondary`, bodyMedium, centered below dots |

Source: D-06 through D-09; NuvioTV ProfileSelectionScreen.kt verified shake values; PIN overlay background is Claude's discretion (full-screen chosen over dimmed overlay for PIN focus clarity).

## Interaction States

### Profile Avatar Card (Selection Screen)

| State | Visual |
|-------|--------|
| Default (unfocused) | `NexioColors.BackgroundCard` background, no border, scale 1.0 |
| Focused | scale 1.15x, 2dp `NexioColors.FocusRing` border, `NexioColors.FocusBackground` behind card |
| Locked (has PIN) | Lock icon badge (16dp, `NexioColors.TextSecondary`) bottom-right of avatar |
| Disabled | Not applicable — all profiles are selectable (locked ones show PIN entry after) |

### PIN Numpad Cell

| State | Visual |
|-------|--------|
| Default (unfocused) | `NexioColors.BackgroundCard` background, no border |
| Focused | 2dp `NexioColors.FocusRing` border |
| Disabled (rate-limited) | `focusable(enabled = false)`, 40% alpha on text |
| Pressed / selected | DPAD_CENTER event triggers digit entry, no persistent pressed state |

### Sidebar Profile Row

| State | Visual |
|-------|--------|
| Active profile (collapsed) | `NexioColors.BackgroundCard` background, profile name + expand arrow |
| Focused | 2dp `NexioColors.FocusRing` border (matches existing `SidebarNavItem`) |
| Expanded | `AnimatedVisibility` reveals other profile rows below, arrow rotates 180deg |
| Other profile row (focused) | Same focus ring treatment as nav items |

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| 10-foot legibility | Minimum 16sp for all interactive labels; avatar initial at 40% of avatar size (38.4sp for 96dp avatar) |
| D-pad completable (UI-03) | Every interactive element has `FocusRequester`; initial focus auto-requested via `repeat(2) { withFrameNanos {} }` + `requestFocus()` |
| Focus not lost on screen exit | `LaunchedEffect(hasSelectedProfileThisSession)` fires `contentFocusRequester.requestFocus()` after selection screen exits |
| PIN input validation | `value.filter(Char::isDigit).take(4)` — digits only, max 4 characters |
| Rate-limit numpad disable | `focusable(enabled = retryAfterSeconds <= 0)` — not `focusProperties { canFocus = false }` |
| Back key on sidebar section | `BackHandler(enabled = profileSectionExpanded)` innermost — collapses section, not full sidebar |
| Session flag | `remember {}` (not `rememberSaveable`) — strict once-per-process semantics, resets on cold launch |

Source: RESEARCH.md anti-patterns section, Pitfall 1, Pitfall 3, Pitfall 4.

**1. Create `nexio-web/composables/useProfileStore.ts`**

A composable that manages profile CRUD state. It should:
- Export a `useProfileStore()` function returning reactive state and methods
- State shape:
  ```typescript
  type ProfileState = {
    profiles: ProfileRow[]
    loading: boolean
    error: string | null
    selectedProfileIndex: number | null
    activeTab: 'auth' | 'catalogs' | 'formatter'
    saving: boolean
    deleteTarget: ProfileRow | null  // non-null = show delete modal
  }
  ```
- `ProfileRow` type:
  ```typescript
  type ProfileRow = {
    id: string
    user_id: string
    profile_index: number
    name: string
    avatar_color_hex: string
    avatar_url: string | null
    uses_primary_addons: boolean
    uses_primary_plugins: boolean
    created_at: string
    updated_at: string
  }
  ```
- Methods:
  - `fetchProfiles()` — GET `/api/account/profiles/` with bearer token from Supabase session. Use `$fetch` or `useFetch` following existing portal patterns. Obtain the token from Supabase client: `const { data: { session } } = await useSupabaseClient().auth.getSession()` then use `session.access_token` in Authorization header.
  - `upsertProfile(profileIndex: number, name: string, avatarColorHex?: string)` — POST to `/api/account/profiles/upsert`
  - `deleteProfile(profileIndex: number)` — POST to `/api/account/profiles/delete`
  - `selectProfile(profileIndex: number)` — sets `selectedProfileIndex`
  - `deselectProfile()` — sets `selectedProfileIndex` to null
  - `setActiveTab(tab: 'auth' | 'catalogs' | 'formatter')` — sets the tab
  - `requestDelete(profile: ProfileRow)` — sets `deleteTarget` (opens modal)
  - `cancelDelete()` — clears `deleteTarget`
  - `confirmDelete()` — calls deleteProfile, clears deleteTarget, refreshes profiles
  - `nextAvailableIndex()` — returns the lowest unused profile_index (2-4), or null if all used
- Use a shared singleton pattern (module-level reactive state) so all components share the same state, similar to how usePortalStore works.
- On all API calls, include `Authorization: Bearer ${session.access_token}` header.
- On error, set `state.error` to the error message string.
- On success of upsert/delete, call `fetchProfiles()` to refresh the list.

Create ProfileSettingsSyncService implementing the v8 per-profile settings blob sync contract. This service serializes per-profile DataStore preferences into typed JSON blobs, pushes/pulls via dedicated Supabase RPCs keyed by profileId, and observes DataStore changes with flatMapLatest debounce.

Purpose: Enables per-profile settings to sync independently to Supabase (SYNC-02), ensuring Profile 2 changes never overwrite Profile 1 data. This is the clean break from v7 per D-03.
Output: ProfileSettingsSyncService.kt, ProfileSettingsBlobResponse model, unit tests.

private fun encodePreferenceValue(rawValue: Any?): JsonObject? {
    return when (rawValue) {
        is String  -> buildJsonObject { put("type", "string");  put("value", rawValue) }
        is Boolean -> buildJsonObject { put("type", "boolean"); put("value", rawValue) }
        is Int     -> buildJsonObject { put("type", "int");     put("value", rawValue) }
        is Long    -> buildJsonObject { put("type", "long");    put("value", rawValue) }
        is Float   -> buildJsonObject { put("type", "float");   put("value", rawValue.toDouble()) }
        is Double  -> buildJsonObject { put("type", "double");  put("value", rawValue) }
        is Set<*>  -> buildJsonObject {
            put("type", "string_set")
            putJsonArray("value") { rawValue.filterIsInstance<String>().forEach { add(it) } }
        }
        else -> null
    }
}

    Package: `com.nexio.tv.core.sync`

    Full class structure:

    ```kotlin
    @Singleton
    class ProfileSettingsSyncService @Inject constructor(
        private val authManager: AuthManager,
        private val postgrest: Postgrest,
        private val profileManager: ProfileManager,
        private val profileDataStoreFactory: ProfileDataStoreFactory
    ) {
        private val scope = CoroutineScope(SupervisorJob() + Dispatchers.IO)
        private val syncMutex = Mutex()
        private val syncedFeatures = listOf(
            "trakt_settings",
            "simkl_settings",
            "player_settings",
            "layout_preferences",
            "theme_settings"
        )

        @Volatile private var applyingRemoteBlob = false
        private var skipNextPushSignature: String? = null
        private var observerJob: Job? = null
    ```

    **Key methods to implement:**

    **`fun startObserving()`** — Called once after construction (from init block or from StartupSyncService):
    - Launch `observerJob` in `scope`
    - Use `profileManager.activeProfileId.flatMapLatest { profileId -> ... }` to restart the inner flow on profile switch (this automatically cancels pending debounces per Pitfall 3)
    - Inside flatMapLatest: `combine()` all DataStore preference flows for all `syncedFeatures` using `profileDataStoreFactory.get(profileId, feature).data`
    - Chain: `.drop(1)` (skip initial emission) -> `.debounce(2000)` (D-01: 2s debounce) -> `.collect { pushBlobForProfile(profileId) }`
    - Guard inside collect: `if (applyingRemoteBlob) return@collect`

    **`suspend fun pushBlobForProfile(profileId: Int): Result<Unit>`** — Serializes all per-profile settings into a JSON blob and pushes:
    - Acquire `syncMutex.withLock { ... }`
    - For each feature in `syncedFeatures`:
      - Get DataStore: `profileDataStoreFactory.get(profileId, feature)`
      - Read current preferences: `store.data.first()`
      - For each preference entry in `prefs.asMap()`: encode key name and value using `encodePreferenceValue(entry.value)` (see interface block above for full implementation)
      - Build a `JsonObject` per feature keyed by preference key name
    - Combine all feature blobs into a top-level `JsonObject` keyed by feature name
    - Compute signature: `blob.toString().hashCode().toString()` — compare with `skipNextPushSignature`; if match, clear skip and return early (prevents echo push after pull)
    - Build params: `buildJsonObject { put("p_profile_id", profileId); put("p_settings_json", blob.toString()); put("p_platform", "tv") }`
    - Call: `withJwtRefreshRetry { postgrest.rpc("sync_push_profile_settings_blob", params) }`
    - Log: `Log.d("ProfileSettingsSyncService", "Pushed settings blob for profile $profileId")`

    **`suspend fun pullBlobForProfile(profileId: Int): Result<Unit>`** — Pulls blob from Supabase and applies:
    - Acquire `syncMutex.withLock { ... }`
    - Build params: `buildJsonObject { put("p_profile_id", profileId); put("p_platform", "tv") }`
    - Call: `withJwtRefreshRetry { postgrest.rpc("sync_pull_profile_settings_blob", params).decodeAs<ProfileSettingsBlobResponse>() }`
    - Parse `response.settingsJson` as a `JsonObject` (using `Json.parseToJsonElement`)
    - Set `applyingRemoteBlob = true` before applying
    - For each feature key in the parsed blob:
      - Get DataStore: `profileDataStoreFactory.get(profileId, feature)`
      - Call `store.edit { prefs -> ... }` and apply each encoded preference using `applyEncodedPreference(prefs, key, valueObj)`
    - Set `skipNextPushSignature` to the blob hash to prevent echo push
    - Set `applyingRemoteBlob = false` in a finally block
    - Log: `Log.d("ProfileSettingsSyncService", "Pulled settings blob for profile $profileId")`

    **`private fun encodePreferenceValue(rawValue: Any?): JsonObject?`** — Exactly as shown in the interfaces block above. Handles String, Boolean, Int, Long, Float (toDouble), Double, Set<*> (as string_set).

    **`private suspend fun applyEncodedPreference(prefs: MutablePreferences, key: String, valueObj: JsonObject)`** — Reverse of encode:
    - Read `type` string from valueObj
    - Match on type:
      - `"string"` -> `prefs[stringPreferencesKey(key)] = valueObj["value"]!!.jsonPrimitive.content`
      - `"boolean"` -> `prefs[booleanPreferencesKey(key)] = valueObj["value"]!!.jsonPrimitive.boolean`
      - `"int"` -> `prefs[intPreferencesKey(key)] = valueObj["value"]!!.jsonPrimitive.int`
      - `"long"` -> `prefs[longPreferencesKey(key)] = valueObj["value"]!!.jsonPrimitive.long`
      - `"float"` -> `prefs[floatPreferencesKey(key)] = valueObj["value"]!!.jsonPrimitive.float`
      - `"double"` -> `prefs[doublePreferencesKey(key)] = valueObj["value"]!!.jsonPrimitive.double`
      - `"string_set"` -> `prefs[stringSetPreferencesKey(key)] = valueObj["value"]!!.jsonArray.map { it.jsonPrimitive.content }.toSet()`

    **`private suspend fun <T> withJwtRefreshRetry(block: suspend () -> T): T`** — Same pattern as AccountSettingsSyncService.

    **`private fun buildSettingsSignature(blob: JsonObject): String`** — Returns `blob.toString().hashCode().toString()`.

    **`fun stopObserving()`** — Cancel `observerJob`.

| T-04-08 | Repudiation | Echo push after pull | mitigate | `applyingRemoteBlob` flag + `skipNextPushSignature` comparison prevent sync loops; Mutex serializes operations |

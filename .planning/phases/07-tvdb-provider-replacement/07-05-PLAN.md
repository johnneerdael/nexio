<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Catalog/addon IDs -> Home provider routing | Home rows contain IDs from addons and external catalogs |
| Provider routing -> Home cache/image prefetch | Metadata controls visible titles and image URLs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Information Disclosure | Home telemetry/logs | mitigate | Emit only event names and item keys; never log TVDB credentials, PIN, bearer token, or full request bodies |
| T-07-02 | Repudiation | Home provider routing | mitigate | Emit `tmdb_tv_skipped` and `tvdb_fallback_tmdb` through existing `onLog` telemetry for catalog hydration |
| T-07-03 | Tampering | Home metadata cache/provider output | mitigate | Consume `TvMetadataRouter` provider-neutral results; do not write TVDB data through TMDB cache methods |
| T-07-04 | Tampering | Home ID routing | mitigate | Series items must call TVDB identity via router before any TMDB ID conversion |
</threat_model>

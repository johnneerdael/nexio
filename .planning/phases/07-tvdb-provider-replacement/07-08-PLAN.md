  <action>
Add a shared internal helper in `HomeViewModelContinueWatching.kt`:
```kotlin
internal fun shouldEnrichContinueWatchingProviderMetadata(
    items: List<ContinueWatchingItem>,
    traktUpNextItems: List<ContinueWatchingItem.NextUp>,
    settings: TmdbSettings
): Boolean {
    if (!settings.useBasicInfo) return false
    if (settings.isActive) return true
    return items.any { item -> isSeriesType(item.contentType()) } ||
        traktUpNextItems.any { item -> isSeriesType(item.contentType()) }
}
```

Use this helper in both current gate sites:
- In `loadContinueWatchingPipeline`, replace `if (settings.isActive && settings.useBasicInfo)` with `if (shouldEnrichContinueWatchingProviderMetadata(items, traktUpNextItems, settings))`.
- In `enrichContinueWatchingWithCurrentSettings`, move `val currentItems = _uiState.value.continueWatchingItems` and `val currentTraktItems = _uiState.value.traktUpNextItems` before the gate, then replace `if (!settings.isActive || !settings.useBasicInfo) return` with `if (!shouldEnrichContinueWatchingProviderMetadata(currentItems, currentTraktItems, settings)) return`.

Do not inject `TvdbSettingsDataStore` into `HomeViewModel` in this task. The router owns TVDB active/inactive decisions; this gate only makes series rows reachable when TMDB is disabled. Do not broaden to movies when TMDB is disabled.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Continue Watching snapshot -> provider routing | Snapshot content IDs and video IDs can be malformed or provider-prefixed |
| Provider metadata -> Home display metadata | TVDB/TMDB values are merged into rows shown on Home |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Information Disclosure | Continue Watching logs/tests | mitigate | Do not log TVDB credentials; tests use mocked router decisions only |
| T-07-02 | Repudiation | Continue Watching provider routing | mitigate | Use `TvMetadataRouter` for series so fallback/skipped-TMDB diagnostics are centralized |
| T-07-03 | Tampering | Continue Watching display metadata | mitigate | Preserve `HomeDisplayMetadata.mergeFallback` semantics and do not mix TMDB cache namespaces with TVDB output |
| T-07-04 | Tampering | Continue Watching ID routing | mitigate | Call TVDB identity through router before any `tmdbService.ensureTmdbId` for series |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TVDB metadata -> timing calculator | Untrusted `aired`, `airsTime`, country, network, and platform strings influence availability |
| Timing calculator -> Continue Watching gate | Calculated instants decide whether rows are visible |
| Timing diagnostics -> logs/debug surfaces | Diagnostic reason and local availability time may be visible in debug output |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering / Denial of Service | `TvdbAirAvailabilityCalculator.parseAirsTime` | mitigate | Parse with `runCatching` and explicit `DateTimeFormatter` list; invalid strings return `DATE_ONLY` with `invalid_time`, never crash |
| T-08-02 | Tampering | `TvdbAirAvailabilityCalculator` source policy | mitigate | Return `missing_timezone_policy` when source zone is unknown; do not use device timezone or UTC as fake precision |
| T-08-03 | Information Disclosure | Timing diagnostics | mitigate | Store only reason codes, source policy/zone, and computed local time; no TVDB credentials, tokens, request payloads, or provider secrets |
| T-08-04 | Spoofing | Provider `firstAiredMs` vs TVDB exact fields | mitigate | `AirDateGate` prioritizes `tvdbAvailabilityInstantMs` over provider timing so Trakt/Simkl cannot override TVDB exact timing when present |
</threat_model>

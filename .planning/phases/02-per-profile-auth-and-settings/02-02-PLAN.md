   ```kotlin
       @ApplicationContext private val context: Context
   ```

   ```kotlin

               accountId = preferences[accountIdKey],
   ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Profile A data -> Profile B read | Profile 2 must not read Profile 1's Simkl access token or account ID |
| Write path -> active profile | All Simkl DataStore writes must target the currently active profile |

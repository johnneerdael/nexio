<objective>
Migrate TraktAuthDataStore and TraktSettingsDataStore from singleton Context-based delegates to the ProfileDataStoreFactory pattern, making all Trakt auth tokens and settings per-profile reactive. Create shared test helpers (FakeProfileDataStoreFactory, FakeProfileManager) reused by all subsequent profile DataStore tests.

Purpose: Trakt is the most complex auth integration (refresh tokens, device flow, scrobble state). Migrating it first validates the factory pattern for all other stores. Per D-09 and D-10, auth stores come first, grouped with their settings store.

Output: 2 migrated production files, 2 test files, 2 shared test helpers.
</objective>

package com.nexio.tv.data.local

import androidx.datastore.core.DataStore
import androidx.datastore.preferences.core.PreferenceDataStoreFactory
import androidx.datastore.preferences.core.Preferences
import java.io.File
import java.util.concurrent.ConcurrentHashMap

class FakeProfileDataStoreFactory(private val testDir: File) {
    private val stores = ConcurrentHashMap<String, DataStore<Preferences>>()

    fun get(profileId: Int, featureName: String): DataStore<Preferences> {
        val key = if (profileId == 1) featureName else "${featureName}_p$profileId"
        return stores.getOrPut(key) {
            PreferenceDataStoreFactory.create { File(testDir, "$key.preferences_pb") }
        }
    }
}

**Step 3 — Migrate TraktAuthDataStore.kt**:

1. Delete the top-level `private val Context.traktAuthDataStore: DataStore<Preferences> by preferencesDataStore(name = "trakt_auth_store")` delegate entirely.
2. Change the class signature from:
   ```kotlin
   @Singleton
   class TraktAuthDataStore @Inject constructor(
       @ApplicationContext private val context: Context
   )
   ```
   to:
   ```kotlin
   @Singleton
   @OptIn(ExperimentalCoroutinesApi::class)
   class TraktAuthDataStore @Inject constructor(
       private val factory: ProfileDataStoreFactory,
       private val profileManager: ProfileManager
   )
   ```
3. Add companion object: `companion object { private const val FEATURE = "trakt_auth_store" }`
4. Add store helper: `private fun store(profileId: Int = profileManager.activeProfileId.value) = factory.get(profileId, FEATURE)`
5. Replace `val state: Flow<TraktAuthState> = context.traktAuthDataStore.data.map { ... }` with:
   ```kotlin
   val state: Flow<TraktAuthState> = profileManager.activeProfileId.flatMapLatest { profileId ->
       store(profileId).data.map { preferences ->
           TraktAuthState(
               accessToken = preferences[accessTokenKey],
               refreshToken = preferences[refreshTokenKey],
               tokenType = preferences[tokenTypeKey],
               createdAt = preferences[createdAtKey],
               expiresIn = preferences[expiresInKey],
               username = preferences[usernameKey],
               userSlug = preferences[userSlugKey],
               deviceCode = preferences[deviceCodeKey],
               userCode = preferences[userCodeKey],
               verificationUrl = preferences[verificationUrlKey],
               expiresAt = preferences[expiresAtKey],
               pollInterval = preferences[pollIntervalKey]
           )
       }
   }
   ```
6. Replace every `context.traktAuthDataStore.edit { ... }` with `store().edit { ... }` in all 7 suspend functions (saveToken, saveUser, saveDeviceFlow, updatePollInterval, clearDeviceFlow, clearAuth). This is a find-replace of `context.traktAuthDataStore` with `store()`.
7. Update imports: add `import kotlinx.coroutines.ExperimentalCoroutinesApi`, `import kotlinx.coroutines.flow.flatMapLatest`, `import com.nexio.tv.core.profile.ProfileManager`. 8. Keep the `TraktAuthState` data class exactly as-is (it stays in the same file).

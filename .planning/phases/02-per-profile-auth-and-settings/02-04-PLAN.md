## Trust Boundaries

| Boundary | Description |
|----------|-------------|

| Non-default profile -> shared settings | Non-default profiles must not see or navigate to shared settings (debrid, API keys) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-11 | Tampering | AccountSettingsSyncService | mitigate | `recentlySwitchedProfile` flag suppresses push for 2 seconds after `activeProfileId` changes; prevents the `flatMapLatest` re-emission from all 6 stores being interpreted as a settings mutation and triggering a cross-profile push; guard placed alongside existing `isApplyingRemote` check |
| T-02-12 | Tampering | Settings UI (shared settings) | mitigate | `isPrimaryProfile` gates shared integration hub entries in `IntegrationSettingsContent`; only profile 1 (isPrimary) sees Debrid, Tmdb, Omdb, Imdb, MdbList, AnimeSkip, SubtitleTranslation, PosterRatings, TheIntroDb, YouTubeTrailerLogin entries; non-primary profiles see only Trakt and Simkl; safety `LaunchedEffect` redirects to Hub if a non-primary profile is on a shared section |

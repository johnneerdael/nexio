<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TVDB `/updates` -> local cache | Untrusted update payloads determine which cache entries are removed. |
| Update processor -> cursor store | A stored cursor controls whether future changed records are skipped. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01-01 | Tampering | `TvdbUpdateProcessor` | mitigate | Validate entity type, record ID, timestamp, and method before mutation; unknown events emit `UNKNOWN_UPDATE_EVENT` instead of broad purge. |
| T-10-01-02 | Denial of Service | `TvdbUpdateStateStore` | mitigate | Advance `last_successful_cursor` only after all pages and cache invalidations complete. |
| T-10-01-03 | Information Disclosure | update diagnostics | mitigate | Use `TvdbReliabilityDiagnostic.sanitized()` for refresh errors and never include Authorization headers or TVDB credentials. |
</threat_model>

# libplacebo Build Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eliminate the 10.7 GB of unnecessary libplacebo build artifacts on disk, slim future rebuild outputs from ~1 GB per ABI to ~50 MB, and remove the spurious `libshaderc_shared.so` runtime dependency from the APK so the only persistent payload from this toolchain is the bytes statically linked into FFmpeg's `.so` files.

**Architecture:** Three independent phases that can ship as separate commits.
1. Stop tracking build artifacts in git and delete them — pure cleanup, no build-pipeline change.
2. Modify `build_libplacebo_android.sh` so its install step strips debug symbols and prunes outputs not used downstream — a slim regeneratable cache.
3. Reconfigure libplacebo to link `libshaderc_combined.a` instead of `libshaderc_shared.so`, eliminating the only runtime payload from the prebuilt directory and shrinking the APK by ~25 MB.

**Tech Stack:** bash + meson + cmake + ninja + Android NDK + git submodules. The build script lives in the `media` submodule (`origin: johnneerdael/media.git`); changes there require committing inside the submodule and bumping the submodule pointer in the parent repo.

**Working directory assumption:** all shell commands assume `pwd = /Users/jneerdael/Scripts/nexio` (the parent repo root) unless explicitly stated.

**Why this plan exists:** During DV5 leak debugging on 2026-04-25, `git status` surfaced a 4.1 GB `third_party/libplacebo-prebuilt-v7.360.0/` directory plus a 6.6 GB `.libplacebo-build/` cache. Audit (`ffvideo.cpp` includes + APK contents) showed the actual runtime payload from this entire toolchain is one 6 MB `libshaderc_shared.so` per ABI plus the libplacebo code statically linked into FFmpeg. Everything else is bloat from `cmake --install` / `meson install` writing the full developer install layout (unstripped static archives, the `glslc` CLI, headers, CMake configs) that the script then never deletes.

# touches. Keeps the prefix to ~50 MB per ABI instead of ~1 GB.

  rm -rf "${prefix}/bin"

  rm -rf "${prefix}/lib/cmake"
  rm -rf "${prefix}/share/cmake"

  # SPIRV-Cross runtime helpers we don't link against.
  rm -rf "${prefix}/share/spirv_cross_core"
  rm -rf "${prefix}/share/spirv_cross_cpp"

  rm -rf "${prefix}/share/spirv_cross_reflect"
  rm -rf "${prefix}/share/spirv_cross_util"

  # (-Dglslang=disabled). Nothing links it.
  rm -f "${prefix}/lib/libglslang.a"
  rm -f "${prefix}/lib/libglslang-default-resource-limits.a"
  rm -f "${prefix}/lib/libMachineIndependent.a"

## Phase C — Eliminate runtime libshaderc_shared.so dependency (investigation + fix)

The APK currently ships `libshaderc_shared.so` (~6 MB per ABI) only because libplacebo's meson build picks up shaderc's `.so` instead of the static archive at link time, leaving FFmpeg's `libavfilter.so` with a runtime `NEEDED` on it. If we force libplacebo to link `libshaderc_combined.a` statically, that NEEDED disappears and we can drop the `syncShadercRuntimeJniLibs` Gradle task entirely — APK shrinks by ~25 MB across all ABIs and the prebuilt directory's runtime payload becomes literally zero.
